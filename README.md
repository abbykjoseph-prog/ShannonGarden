# Shannon Boudreau Gardens

Marketing site for Shannon Boudreau Gardens: garden design and care in Toronto and the GTA.
Next.js 14 (App Router), TypeScript, Tailwind. Deployed on Vercel.

```bash
npm install
npm run dev
```

- **Copy and business facts** live in `lib/site.ts`. Search for `TODO` to find placeholders to confirm.
- **Logo**: `npm run logo` regenerates `public/logo-long.png` and `public/logo-long-light.png` from `Garden Logo Long.png` (the original is never modified).
